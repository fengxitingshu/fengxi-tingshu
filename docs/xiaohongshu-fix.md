小红书对「技术接单 / 逆向 / 爬虫 / 数据采集」类内容，在**资料区（昵称 / 头像 OCR / 简介 / 背景图 OCR）**是零容忍的：

## 二、修正原则（务必照做）

1. 资料区（昵称 / 头像 / 简介 / 背景）**不出现**任何敏感词：
   逆向 · 爬虫 · 数据采集 · 接口 · 破解 · 脚本 · 接单 · 代做 · 私信 · 微信 · 进群
2. 技术属性**藏到笔记正文**里（科普向笔记相对宽松），招牌保持「个人 IP / 兴趣」人设。
3. 简介 / 背景**不写任何引导词**，先靠笔记自然吸粉，评论区再互动。
4. 改完合规版后，**静止半天~1 天**再发笔记，别又频繁改资料。
