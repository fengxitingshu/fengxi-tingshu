# 小红书装修方案 · 枫兮脚本接单

> 适用对象：咱们的脚本服务（① Python 自动化小工具定制 ② 接口开发/数据采集 ③ App 接口抓包逆向）。
> 核心理念：**小红书吃"人设 + 干货"，不吃"硬广接单号"**。先把脚本包装成"效率工具 / 技术分享"吸粉，再用站内方式合规转化。

---

## 0. 核心思路（先读这段）

| 维度 | 闲鱼打法 | 小红书打法（本方案） |
|------|----------|----------------------|
| 定位 | 接单号、卖服务 | 技术副业博主、效率工具分享者 |
| 流量来源 | 搜索 + 擦亮 | 推荐流 + 搜索，封面点击率决定生死 |
| 内容 | 9 图商品卡 | 干货笔记（教程/爽文/科普）+ 人设 |
| 转化 | 拍下成交 | 干货吸粉 → 小红书群聊 → 私信 → 站内成交 |
| 红线 | 不写微信 | **不写任何站外联系方式**，违规封号 |

> 关键判断：**差异款（App 抓包逆向）在小红书最敏感**。不要直接发"代逆向接单"，包装成"安卓逆向技术科普"，且每一篇都带合规声明（仅公开数据、不碰隐私/付费墙）。这条线建议小红书只做人设展示，真正接单靠 GitHub / 知乎 / 群。

## 4. 爆款笔记模板

### 4.1 封面公式（小红书 3:4 竖图，1080×1440）
```
[大字痛点/爽点]  +  [emoji]  +  [一行副标题]  +  [人设小标]
```
- 痛点型："还在手动整理 Excel？😩"
- 爽点型："5 分钟干完 3 小时 ✅"

- 见 `图片/` 里三方向各 3 张封面（已渲染）。

### 4.2 标题公式 + 标题库（直接抄）
公式：`痛点 + 方案` / `数字 + 结果` / `反差 + 好奇`

标题库（按方向）：

引流款（办公自动化）：
1. 还在手动整理 Excel？这个 Python 脚本 5 秒搞定
2. 打工人必看：3 个让我准时下班的自动化脚本
3. 300 个文件怎么快速改名归类？代码来救场
4. 别再熬夜做报表了，定时任务帮你自动跑
5. 副业第一天：用脚本帮人整理数据赚了杯奶茶

利润款（数据采集）：

7. 接口看不懂？用 Python 把公开接口封装成工具
8. 登录态总过期？Cookie 保鲜这点事讲清楚
9. 动态网页抓不到？无头浏览器了解一下

差异款（逆向科普，谨慎）：

14. 逆向不是为了干坏事：只做公开合规数据

## 5. 三方向内容包装（针对咱们的脚本）

**引流款 → 办公自动化系列**
- 钩子：打工人、省时间、下班自由。
- 内容：文件批量处理、Excel 合并清洗、定时任务、表单自动填。
- 转化话术："这类小工具我也能帮你定制，私信说需求。"

**利润款 → 数据采集系列**
- 钩子：把公开数据变成你能用的工具。
- 内容：接口分析、签名复现、登录态维持、动态页抓取。
- 转化话术："复杂接口可定制封装，脱敏样本私信我。"

**差异款 → 逆向科普系列（最高风险，谨慎）**
- 钩子：别人看不懂的接口，我拆给你看。
- 内容：只做**公开合规数据**的技术科普，每篇带合规声明。
- 转化话术：小红书只做人设，**真正接单走 GitHub/知乎/群**，避免平台判定违规。
- 合规声明模板（每篇必带）："本文仅用于技术学习，只分析公开合规数据，不涉及任何隐私、付费墙绕过或破解行为。"

## 7. 发布与运营节奏

- **养号期**：第 1–7 天，每天活跃 30 分钟，发 1–2 篇轻量干货，不急转化。
- **稳定期**：隔日更或日更，固定时段发（早 8–9 / 午 12–13 / 晚 19–22 流量高）。
- **互动**：评论区主动回，引导"进群聊"；群内发作品、答疑、软性展示能力。
- **数据**：盯"小眼睛"（阅读），低于 100 的封面/标题要换钩子重发。
