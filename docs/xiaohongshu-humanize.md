# 小红书笔记去 AI 腔 & 真实化指南

## 一、置顶功能在哪
小红书 → 右下角「我」→ 进个人主页 → 点开要置顶的笔记（进详情页）→ 右上角「···」→ 菜单点「置顶」。
置顶后该笔记排最前、带"置顶"标。
若菜单没有"置顶"：账号还新/活跃度不够，先养号几天（每天刷、赞、评）通常就出现；也可能在"管理笔记"里。

## 二、为什么提示「AI 生成」
1. 配图是模板生成的（纯色+大字+emoji），算法识别为"非原创/AI 图"。
2. 文案太工整（分点+emoji列表+营销腔），被判 AI 生成文本。
小红书对 AIGC 有标识机制，识别到就标，影响真实感和推荐。

## 三、怎么办

### 1) 配图换真实截图（最有效，别用模板大字图）
- 引流款：代码编辑器里你的脚本 + 运行前后文件夹对比图
- 利润款：浏览器 F12→Network 看到的接口 + 你的请求代码（打码敏感信息）
- 差异款：抓包工具(Charles/mitmproxy)界面 + 脱敏后的请求（打码）
真实截图不会被标 AI 图，点击率也更高。

### 2) 文案去 AI 腔（口语化、有真人感）
原则：少分点、少 emoji 堆砌、加个人场景和语气词，像跟朋友聊。

【置顶·自我介绍】
最近老有朋友问我：你咋天天准点下班？
其实就靠一堆自己攒的小脚本，把重复活全扔给电脑了😂
比如上周帮人整理三百多个乱七八糟的文件，我写了个小东西，五秒全分好类，他当场愣住。
我自己就是个写代码的小透明，平时爱折腾这些效率玩意儿。这个号就随手记点东西，顺便分享些能直接抄走用的小技巧。
有啥想自动化的活儿，也欢迎来唠唠～

【引流款】
说真的，手动整理 Excel 这事我以前也干过，累得不行。
后来写了个脚本：扫一遍文件夹、按关键词分目录、多进程一起跑，三百个文件五秒搞定，喝口水的功夫就没了☕
类似的重复手工活其实都能脚本化：批量改名、表格合并清洗、定时跑任务、自动填表……
你要是也有这种烦人的活，跟我说说具体场景，能帮就帮。

【利润款】
好多人问我网页上的数据能不能自动存下来，能，但得先懂三件事。
一是数据从哪来：F12 打开开发者工具，刷一下页面，真正的接口大多藏在 Network 里。
二是要不要带"钥匙"：很多接口要登录态，过期就抓不到，得想办法保鲜。
三是动态页：JS 渲染的，得上 Playwright 之类等它渲染完再取。
只弄公开、你有权碰的数据哈，隐私相关的我一概不接。复杂的接口我可以帮你封成简单调用。

【差异款】（带合规声明，正文用"接口分析"代替"逆向"降敏）
新手抓 App 接口经常碰壁：请求发出去，回的却是空的。
多半是"签名"在拦。说人话就是服务器给请求加了把防伪锁——客户端把参数加密钥算个 sign，服务器自己再算一遍，对不上就拒。
接口分析就是：抓到真实请求 → 找到那段算法 → 用 Python 复现，就能自己构造合法请求了。
声明一下：我只做技术学习，只碰公开合规的数据，隐私、付费墙、破解这些一概不沾。

### 3) 已经被标了怎么处理
- 编辑笔记看能否取消标识（多数不能），或删除重发（用上面的真实内容）。
- 不必过度焦虑：带 AI 标不必然限流，但真实内容肯定更稳。
- 小红书要求 AI 内容主动声明，被动被标说明内容特征太"AI"，靠真实截图+口语文案消解。
