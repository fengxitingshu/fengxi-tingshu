# 闲鱼接单操作手册（合规技术服务）

> 本手册是「枫兮听书」作者做**个人技术服务副业**的操作规范。
> 与 App 的非营利定位**分开运营**：不要用「枫兮听书作者」身份接单，避免把 App 的干净定位搞脏或被关联。
> 接单是合法的个人劳动收入；但**单子性质会传导**——客户让你爬盗版/破解会员，写了就是帮助侵权。

## 0. 先读：红线（违反任一即拒单）

🚫 **四不碰**
1. 破解验证码（打码平台、识别模型）
2. 绕过付费墙 / 会员限制 / DRM
3. 批量抓取受版权保护的内容（整站小说 / 音频 / 视频）
4. 撞库、盗号、抓取个人隐私数据

🔴 **一条铁律**：**不问用途不接，用途不明不接。** 下单前让客户说明用途，无法确认合法来源的，一律不接。

✅ **能接的**：你（或客户）**有权访问**的公开/授权数据 —— 公开数据爬取、接口分析、登录态维持、自动化工具、数据清洗入库。

## 2. 接单工作流（八步闭环）

```
① 接待初筛 → ② 需求登记 → ③ 合规判定 → ④ 报价
      ↓                                        ↓
⑧ 售后好评 ← ⑦ 交付 ← ⑥ 开发 ← ⑤ 拍下/定金
```

| 步骤 | 动作 | 要点 |
|---|---|---|
| ① 接待初筛 | 客户来问，先问「做什么、数据从哪来、自己有没有访问权限」 | **不问用途不接**；一句话露馅（"下某站全本""破解会员"）直接拒 |
| ② 需求登记 | 填《需求登记表》（见第 3 节） | 留痕，避免后期扯皮；脱敏存客户联系方式 |
| ③ 合规判定 | 对照第 0 节红线逐项过 | 四不碰 + 用途不明 = 拒；存疑就拒 |
| ④ 报价 | 引流款低价引流、利润款 100~500、差异款面议 | 复杂单先要脱敏样本再报，别盲报 |
| ⑤ 拍下/定金 | 引导拍下对应链接；利润款可收 30%~50% 定金 | 定金防白嫖；改价用闲鱼「改价」功能 |
| ⑥ 开发 | 本地开发，环境依赖写清楚 | 不把客户密钥硬编码进交付物；用配置文件 |
| ⑦ 交付 | 按《交付模板》（见第 4 节）交付 | 含使用说明 + 免责声明 + 售后范围 |
| ⑧ 售后好评 | 交付后跟进，引导带图好评 | 第一单哪怕不赚也换一条好评，转化差几倍 |

## 5. 闲鱼实操要点（养号与转化）

- **先养号 3~5 天**：实名 + 完善芝麻分/简介，再发链接；新号没信誉接不到利润款。
- **发布 2~3 条**上面的合规链接，标题用软词（数据采集/接口开发/自动化工具）。
- **每天擦亮 + 进相关鱼塘**（Python / 小程序开发 / 数据采集类），新手流量靠这个。
- **低价引流款先跑通一单**，换一条带图好评，后面转化率差好几倍。
- **站外导流**：闲鱼禁直接留微信；话术用「拍下后我发你联系方式」，别在详情页写。
- **改价追价**：引流款 ¥9.9 真实成交时说「这个复杂度要加」，用闲鱼改价功能补差价，比一口价更易成单。

## 6. 与 App 的隔离原则

- **身份隔离**：接单用个人技术服务身份，不挂「枫兮听书」招牌。
- **账号隔离**：别用 App 主群 / 实名主号接灰单；合规单可接，灰单碰都别碰。
- **定位不冲突**：App 走非营利 UGC，闲鱼是个人技术服务收入，两码事，但都要守「合法数据」底线。
- **不联动导流**：别把闲鱼客户往 App 千人群带，反之亦然。

> 一句话：**用你的签名复现 / 抓包 / Android 逆向能力做合规技术服务，靠引流款养号、利润款赚钱、差异款做壁垒；全程只碰公开/授权数据，App 品牌和接单账号分开。**
