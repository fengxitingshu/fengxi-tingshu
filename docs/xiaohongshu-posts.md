## ③ 利润款（封面：利润款_01.png）
**标题**：网站数据怎么自动抓下来？小白也能懂的思路 📊

**正文**：
很多人问我：网页上那些数据，能不能自动存下来？
能，但先搞懂三件事：

🌐 数据从哪来：按 F12 打开开发者工具 → 网络(Network)，刷一下页面，真正的接口往往藏在 XHR / Fetch 里
🔑 要不要带"钥匙"：很多接口要登录态（Cookie / Token），过期就抓不到，得保鲜
🤖 动态页怎么办：JS 渲染的页面，用 Playwright / 无头浏览器等它渲染完再取

⚠️ 只处理公开数据，或你有权访问的数据。用途不明、涉及隐私的一律不接。

## ④ 差异款（封面：差异款_01.png，务必带合规声明）
**标题**：App接口为啥抓不到？先搞懂"签名"是什么 🔍

**正文**：
新手抓 App 接口，经常遇到：请求发出去，返回却是空的 / 报错。
大概率是"签名"在拦你。

简单说，签名就是服务器给请求加的一把"防伪锁"🔒：
📌 客户端把参数 + 一个密钥，按固定算法算出一个 sign 值
📌 服务器收到后自己再算一遍，对不上就拒收

所以逆向要做的是：
1️⃣ 用抓包工具（如 Charles / mitmproxy）拿到真实请求
2️⃣ 定位签名算法（通常在 App 的 so / 代码里）
3️⃣ 用 Python 复现，就能自己构造合法请求
