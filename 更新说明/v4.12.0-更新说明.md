# 枫兮听书 v4.12.0 更新说明

> 发布日期：2026-10-27
> 定位：播放体验打磨（在 v4.11.0 的合规内容 + 合规三件套基础上，把"听"这件事做得更顺手）

## 新增功能

### 1. 播放模式（顺序 / 单曲循环 / 列表循环 / 随机）
- 设置页新增「播放模式」下拉，播放页「更多」菜单也能一键循环切换。
- 四种模式：
  - **顺序播放**：按集顺序往后播（受"自动连播"开关控制是否跳下一集）。
  - **单曲循环**：当前集播完重播本集。
  - **列表循环**：播到最后一集自动回到第一集。
  - **随机播放**：每集播完随机跳到另一集。
- 偏好自动记忆，下次打开沿用。

### 2. 自动连播开关
- 顺序模式下，可关闭"播完自动下一集"。关闭后播完当前集停在该集末尾，不跳下一集。
- 设置页开关 + 播放页「更多 → 自动连播」均可切换。

### 3. 章节列表增强
- **续听位置高亮**：打开书时，自动标出"上次听到第几集"（蓝色"续听"标签），几百集的公版书也能一眼定位。
- **长按章节**：长按任意章节弹出菜单，可「从这集开始收听」或「定位到这集」。

### 4. 首页"继续收听"升级为多本书架
- 首页顶部「继续收听」从单本横幅，升级为**最近在听的多本书架**（取历史最近若干本），每本都能一键续听。
- 只有 1 本历史记录时自动回退为旧版单本样式，保持兼容。

### 5. 悬浮球定时状态角标
- 软件内播放悬浮球（右下角小圆球）在设定定时关闭后，右上角显示剩余时间/集数角标（如"23分""3集"），与播放页按钮、桌面小组件一致。

## 合规说明（重申）
本 App 是**播放与订阅工具**，不提供、不存储任何音频内容。请仅使用：
- **公版书**（版权过期，如四大名著、史记等内置源）
- **播客 RSS**（制作方公开分发的节目）
- **个人自有 / 已授权**的音频（自己的网盘、NAS 等）

请勿用本工具获取、分发受版权保护的有声书等未授权内容。

## 安装包
- 完整版：`枫兮听书-v4.12.0.apk`（含 FFmpeg 软解内核，约 50MB，WMA/APE 等格式可直接播放）
- 升级：覆盖安装即可，书架与历史记录本机保留。
