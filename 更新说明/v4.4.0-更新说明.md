# 枫兮听书 v4.4.0 更新说明

> 2026-10-25 · versionCode 112

## 新增

### 全部网盘支持「网页登录」（自动抓 Cookie）
- 6 家网盘（115 / 天翼 / 夸克 / UC / 百度 / 阿里）全部新增**网页登录**按钮：
  点一下 → App 内弹出网盘官方登录页 → 正常登录（密码/扫码/第三方随意）→
  **登录成功自动抓取 Cookie 并保存、自动关闭返回**，全程无需再开电脑 F12 抄 Cookie
- 抓取判定：每家网盘认准登录成功的标志 Cookie（如 115 的 UID/CID/SEID、
  百度的 BDUSS、夸克/UC 的 __puus、天翼的 SESSION、阿里的 sfstoken），
  齐了才算登录成功，不会存半截 Cookie
- 115 扫码登录、天翼密码登录保留，三种方式任选
- 「配置 Cookie」手动粘贴仍作兜底
