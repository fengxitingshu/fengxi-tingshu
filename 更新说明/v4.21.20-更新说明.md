# v4.21.20 更新说明

> versionCode 212 · 覆盖安装数据不丢（签名一致）

## 修复

1. **百度播放报「转存响应里没有新文件 id」（连续多版的真凶找到了）**
   - 用户截图里的原始响应实证：转存时文件已在盘里的分支，百度返回
     `duplicated.list`，条目只有 `path / file_key / size / server_ctime` 这套字段，
     **没有 `from_fs_id`**——旧版正则只扫 from_fs_id，必然落空。
   - 新版三路并取：JSON 逐项认 `from_fs_id` / `fs_id` / `id` 三种键名
     （优先取 path 与目标文件一致的条目）+ 全文正则 `"(?:from_)?fs_id"` 兜底。
   - `errno=12`（文件已存在）也正确视为转存就绪（此前只认 0/4）。

2. **转存落盘延迟**
   - 转存刚完成后，盘内目录列表可能还没刷出新文件（最终一致）。
     旧版回查一次不到就报错；现在隔 1.5 秒回查一次，最多 5 次（约 8 秒窗口）。

## 新增

1. **功能诊断**（入口：关于 → 问题诊断 → 功能诊断）
   - 可勾选功能块逐块体检：网络连通 / 书源与引擎 / 网盘登录态 / 网盘自动转存 / 播放链路 / 存储空间。
   - 每块给出 ✓ 通过 / ✗ 有问题 + 具体日志 + 耗时，跑完一块显示一块，可一键复制截图反馈。
   - 网盘块会做真请求实测：百度登录态在线校验（bdstoken）、转存目录检查、
     盘内取链接口（filemetas）实测——播放失败时先跑这一块，哪一环断了一眼可见。

2. **网盘链路全程插桩**
   - 解析（wxlist）→ 转存受理 → id 提取 → 盘内回查 → 取链（filemetas）
     每一步结果都记进运行期诊断日志，功能诊断里可回放全过程。
