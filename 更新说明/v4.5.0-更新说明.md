# 枫兮听书 v4.5.0 更新说明

> 2026-10-25 · versionCode 113

## 新增

### 扫描已登录网盘内的有声书
- 已登录的网盘卡片新增**「扫描盘内书」**按钮：自动遍历网盘目录（深度 3 层），
  找出全部含音频文件的文件夹（mp3/m4a/m4b/flac/wav/aac/ogg/wma/opus），
  按「文件夹名 = 书名」整理成书，一键**整本播放**（自动下一集、续播、通知栏照常）
- 不用再找分享链接——自己网盘里存的有声书直接扫出来听
- 支持平台：夸克 / UC / 115 / 天翼 / 百度（阿里云盘因网页接口签名风控暂不支持，分享解析不受影响）

## 修复

### 夸克 / UC 分享解析「书名/章节」结构没法播
- 之前解析只拉分享的第一层，有声书分享「书名/章节.mp3」结构解析出来
  全是文件夹、没有可播放的文件（表现为「解析未生效」）
- 现在自动展开子文件夹（最多 8 个），直接拿到章节文件
