# 枫兮听书 v4.1.0 更新说明（2026-10-25）

## ★★ 修复：本地书源扫不到音频文件
- 媒体库查询不再按「是音乐 / 时长≥20秒」过滤——听书文件常被系统标成非音乐，
  且刚下载、冷门格式的时长可能还没提取，之前会被整批漏掉
- 文件系统兜底扫描改为**始终执行**（之前只要媒体库扫到几首歌就不再兜底，
  `.nomedia` 目录、未被索引的听书文件夹永远缺失）
- 存储权限请求同时兼容 READ_MEDIA_AUDIO 与 READ_EXTERNAL_STORAGE，
  各厂商 ROM（MIUI/鸿蒙等）都能正常弹授权窗

## ★★ 修复：小分辨率下悬浮球播放键歪
- 播放图标居中改用 grid 布局（老 WebView 的 flex 对 SVG 兄弟节点偶发偏移）
- 小屏（宽度 <360px）球体自动缩到 48px，图标与圆环同步缩放
- 拖动起点补偿按压缩放差，抓球不再偏移几个像素
- 位置记忆改为「靠哪边 + 距离 + 纵向比例」，旋转屏幕/换分辨率不再跑偏

## ★ 源识别失败：可救回 + 有诊断
- 章节表为空时**自动清缓存重试一次**（网络抖动/缓存污染可自动恢复）
- 重试仍失败：显示各源的具体报错、来源名，并提供「重试一次」按钮

## ★★ 修复：源列表双向不同步
- 首页删源后「书源管理」还留着、源管理删了首页还在 —— 现在所有源操作后
  首页源缓存与权威源表严格对齐（reconcileHomeSources）

## ★ 首页左上角源下拉：长按操作
- 长按任意源弹出：重命名 / 停用·启用 / 测试连通 / 删除
- 内置源与插件源不可删除（只提供停用）；自定义 JSON 源、Python 源可删
- 首页批量删除对内置/插件源自动改为「停用」并明确提示，不再“点了删除却还在”
