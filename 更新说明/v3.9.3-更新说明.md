# v3.9.3 更新说明

**发布日期**：2026-10-14 ｜ **versionCode**：55 ｜ **包名**：`com.tingshu.app`（可直接覆盖安装）

本次共修复/改进 7 项，全部围绕 v3.9.2 用户实测反馈。

---

## 1. 桌面小组件白卡（终极修复）

**为什么 v3.9.2 还是白的**：v3.9.2 把 RemoteViews 动作集收回到了 3.8.5 实测可用的六类，但仍然白卡。把 3.8.5（你机器上最后一版好用的）与 3.9.2 的布局逐字节反编译对比后，剩下的差异全在**布局结构层**：v3.9.0 重写时引入的封面三层叠 FrameLayout、单层进度格、额外的角标/状态点 TextView、@string 资源引用、0.5dp 分数边距——无法远程判定具体是哪一条压垮了 originOS 桌面，索性全部对齐。

**本版做法**：布局结构与 build() 调用序列 = **v3.8.5 逐字节复刻**（显示格 wgBar 只上色、点击层 wgSeek 只挂点击、六个点击挂点、双 setSelected 跑马灯，一步不多一步不少）。代价是放弃了倍速/定时角标与状态点小圆点——**可用性优先**。

> ⚠️ 升级后请**移除旧小组件再重新添加**，系统会缓存旧视图，只装新包看不到效果。

## 2. 本地书源识别增强

- **书名前缀拆书**：一个文件夹里混着多本书（`书名第1章.mp3` 式命名）现在能自动拆开；平铺在下载目录的书也能认出来（`第X章/集/回/话/节`、`Chapter 07`、`EP03`、`Track 9`、`书名 089.mp3`、纯数字 `001.mp3` 都认）。
- **格式扩充**：新增 ape / mka / oga / m4r / m4p / amr / 3gp（m4a 本来就支持，之前认不出多半是媒体库没索引——见下条）。
- **文件系统兜底扫描**：媒体库漏掉的（`.nomedia` 目录、冷门格式、刚下载还没索引的文件）现在直接扫文件系统补齐。
- **中文数字集数排序**：`第一章/第十章/第二章` 不会再排成 一/三/二，`第三章`=3 参与数值排序。

## 3. 搜索列表与顶部选源条卡顿/乱跳

- 搜索进行中各源陆续回传时，不再反复整表重绘 + 甩回顶部；筛选列表的数据刷新**保持滚动位置**。
- 顶部来源筛选条：内容没变不重建，重建时把横向滚动位置搬回来——点 chip 不再"闪一下、位置跑飞"。
- 卡片点击改走**索引快照**：增量结果再多也不会点错书；收藏按钮不再把整本书 JSON 塞进 onclick（几百张卡片时明显提速）。

## 4. 章节列表滑动卡顿/回弹顶部

- **根因**：已听标记数据总是在你刚开始滑列表时到达 → 整页 innerHTML 重建 → 卡一下 + 弹回顶部。现在改为**就地刷新**（只增删"已"徽标），滚动位置与 DOM 纹丝不动。
- 收藏态、来源名映射变化触发的重绘同样不再回弹顶部。

## 5. 首页左上角下拉菜单加入本地书源

自定义源里开启了「本地书源」后，首页源下拉末尾会出现「自定义源」分组，选中即直接列出扫描到的本地书（点开即详情）。网盘源本质是分享链接解析、没有可浏览列表，不放进首页。

## 6. 首页源下拉支持返回键关闭

下拉展开时按返回键先收起下拉，不再穿透到退页面/退出。

## 7. 已读标记改版

章节列表与选集弹层的已收听标记由绿色对勾 ✓ 改为**绿色圆圈圈住的「已」字**。

## 升级提示

1. **小组件**：移除旧组件 → 重新添加（必做）。
2. 旧备份包可直接恢复（v3.9.2 的校验修复继续有效）。
3. py 源升级后杀进程重进一次即可。
4. 本地书源若之前扫不到书，升级后到「书源管理 → 自定义源 → 本地书源」点一次重新扫描。
