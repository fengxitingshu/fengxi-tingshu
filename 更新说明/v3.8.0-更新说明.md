# 枫兮听书 v3.8.0 更新说明

> 本版只做一件事，但做得比较完整：**备份与恢复**。
> 「我的」页和设置页各有一个入口，进去之后既能备份到手机本地（位置自己选），
> 也能备份到网盘（WebDAV 协议，坚果云 / Nextcloud / 群晖 / 威联通 / Alist 都支持）。

---

## 一、这一版解决的问题

在此之前，书源、收藏、历史、各种设置全部只存在本机。一旦遇到下面任意一种情况，
积累的东西就没了：

- 换手机、换机前忘了导书源，装好新版发现「所有源都不见了」
- 卸载重装（**换签名后必须卸载旧版**，卸载会一并清空本机数据）
- 手滑在源管理里删错源、批量删源删过头
- 想把一台手机上配好的一整套源 + 设置，原样搬给另一台手机

以前只有「书源管理」里能导出/导入书源本身，收藏、历史、播放进度、设置都搬不走。
现在一个备份包全带走。

---

## 二、新增功能

### 1. 备份与恢复入口

两个入口，点进去是同一个页面：

- **「我的」页** → 顶部区域新增「备份与恢复」卡片
- **设置页** → 「备份与恢复」一行

页面从上到下分四块：**备份内容 → 本地备份 → 网络备份（WebDAV）→ 自动备份**，
底部还有一个「执行记录」，实时显示当前在做什么、成功还是失败。

### 2. 备份内容（进页面就能看到具体数量）

| 分类 | 具体包含 |
| --- | --- |
| **书源** | 自定义书源、源分组、每条源的配置（启用状态 / 排序 / 备注）、JS 插件包（整个目录）、Python 源（`.py`）、jar 插件 |
| **收藏与历史** | 收藏的书、收藏分组、播放历史、每本书的播放进度 |
| **软件设置** | 播放 / 缓存 / 外观等全部偏好，以及搜索历史 |

> **备份包不含音频缓存与已下载的音频文件。**
> 一是体积大（单集 10~15MB，几百集就上 GB），二是这些内容随时可以重新获取。
> 所以一份完整备份通常只有几百 KB，上传网盘很快。

### 3. 本地备份（位置自选）

- 点「备份位置」→ 系统文件夹选择器 → 选任意一个文件夹（手机存储、SD 卡、外接 U 盘都行）
- **选一次就长期记住**，之后不用再选
- 点「备份到本机」→ 填个文件名（默认带时间戳，如 `fengxi-20251012-1030.fxbak`）→ 生成备份包
- 恢复到本机：点「从备份包恢复」→ 选一个 `.fxbak` 文件 → 二次确认 → 完成

备份包扩展名是 `.fxbak`（而不是 `.zip`），避免被系统的解压 App 抢走文件关联，
点开时不会被当压缩包处理。

### 4. 网络备份（WebDAV 协议）

**为什么选 WebDAV**：一套协议就能覆盖你提到的全部场景 ——

| 你想用的 | 填什么地址 |
| --- | --- |
| 坚果云 | `https://dav.jianguoyun.com/dav/` |
| Nextcloud / ownCloud | `https://你的域名/remote.php/dav/files/用户名/` |
| 群晖 NAS | `http://NAS地址:5005/` （WebDAV Server 套件） |
| 威联通 NAS | `http://NAS地址:5006/` |
| Alist | `http://你的地址/dav/` |
| 任何标准 WebDAV 服务 | 服务商给的 WebDAV 地址 |

用法：

1. 点「服务器设置」→ 填 **地址 / 账号 / 密码 / 备份目录**（目录默认 `fengxi-backup`）
2. 点「测试连接」→ 显示「正常（xxx ms）」说明通了
3. 点「备份到网盘」→ 自动在网盘建好目录并上传
4. 「网盘备份列表」里能看到所有备份包，每个都有「恢复」和「删除」两个按钮

> **坚果云用户注意**：密码请填「应用密码」（在坚果云网页版 → 账户信息 → 安全选项中生成），
> 不要填登录密码。填错会返回 401，App 会给出这个提示。

### 5. 恢复前自动留底（本版最重要的一条保险）

**每次执行恢复，App 都会先把当前数据自动打一个包存起来**，最多保留 3 份。
这个自动备份在任何恢复路径（本地 / 网盘 / 自动备份列表）都会执行，
而且**如果这一步失败，恢复会直接中止**，绝不在没有退路的情况下动你的数据。

所以如果你恢复之后发现「不对，我还是想要原来那套」，
直接到「自动备份」区域点对应那一条的「恢复」就能退回去。

## 三、可靠性设计（这些坑都绕过了）

备份/恢复是「要么全对、要么全错」的操作，所以底层做了几层保护：

| 风险 | 处理方式 |
| --- | --- |
| **恢复一半断电 / 出错，留半截数据** | ① 恢复前自动备份兜底；② 数据库走**单个事务**，失败自动整体回滚；③ 文件面（插件目录）先改名成 `.bak-<时间戳>`，成功了才删，失败了改回来 |
| **备份包被篡改 / 下载不完整** | 包里带 SHA-256 校验和，恢复第一步就校验，不通过直接拒绝、零改动 |
| **解压炸弹包（恶意超小包解开变超大）** | 单条目上限 16MB、累计上限 32MB，一旦超过立即中止 |
| **路径穿越（包内条目名写成 `../../xxx`）** | 条目名逐段过滤 `.` / `..` / 空段，落盘前再校验目标路径必须落在临时目录内 |
| **数据库被占用（直接替换文件会导致 WAL 不一致）** | 全程不替换 `tingshu.db` 文件，改用「清表 + 事务内重新写入」，语义同样是整体覆盖但不需要关连接 |
| **表结构跨版本变了，恢复时写入不存在的列** | 只写「包里有的、且本机表里也有的」列（列白名单），不会因为版本不同而报错 |
| **服务器证书不受信任** | 给出明确提示「改用 http:// 地址，或为该证书配置受信任的 CA」。**本 App 不会为任何服务器关闭证书校验** |
| **Android 不接受 PROPFIND / MKCOL 这类非标准 HTTP 方法** | 通过反射设置方法名（沿真实继承链逐级查找，并有候选类名兜底） |
| **XML 命名空间前缀各家不同（`D:` / `d:` / 无前缀）** | 解析时只比较标签本地名，忽略前缀；解析异常还有正则兜底 |
| **WebView 的 localStorage 是异步的，取不到会卡住整个备份** | 异步取回 + **2 秒超时兜底**，拿不到就置空继续，绝不卡死 |

## 五、安装说明

- 直接覆盖安装本版即可，**收藏、历史、进度、设置、书源都不会丢**。
- 如果之前装的是**签名不同**的版本（例如从别人那里拿的包），
  需要先卸载旧版再装 —— 卸载会清空本机数据。
  **建议卸载前先做一次备份**（本版新增的功能），装好新版再恢复回来。
- 首次使用网络备份，建议先点「测试连接」确认通了再上传。

## 七、已知边界

- **不含音频文件**：备份包里只有配置数据。换机后已下载的音频需要用「下载管理」重新下一遍。
- **恢复是整体覆盖**，不是合并。也就是恢复之后本机的收藏 / 历史 / 设置会变成包里的那份。
  如果只想拿回一部分，可以先用自动备份退回，再手动处理。
- **自签名证书的 WebDAV 服务器**（部分 NAS 默认配置）连不上，需要改用 `http://` 地址，
  或给证书换一个受信任的 CA 签发。这是有意为之 —— 不为任何服务器关闭证书校验。
