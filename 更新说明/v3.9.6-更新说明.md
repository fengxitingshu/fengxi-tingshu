# v3.9.6 更新说明

**发布日期**：2026-10-14 ｜ **versionCode**：58 ｜ **包名**：`com.tingshu.app`（可直接覆盖安装，**无需卸载**）

> ✅ **这次是真正的根因**。凭你发来的崩溃日志，精确定位到了「一打开就闪退」的问题所在。

---

## 崩溃日志怎么说

```
java.lang.RuntimeException: Unable to start activity ComponentInfo{com.tingshu.app/MainActivity}
Caused by: java.lang.ClassCastException: java.lang.Integer cannot be cast to java.lang.Float
    at android.app.SharedPreferencesImpl.getFloat(SharedPreferencesImpl.java:401)
    at com.tingshu.app.data.Settings.speed(SourceFile:7)
    at com.tingshu.app.MainActivity.onCreate(SourceFile:141)
```

翻译成人话：**App 启动时读取「播放倍速」这个设置，读崩了。**

- 代码里用的是 `SharedPreferences.getFloat("speed_global", 1.0f)`；
- 系统读这个值时会做一次**硬转型** `(Float) 值`；
- 但你手机里 `speed_global` 存的是 **Integer（整数）**，不是 Float；
- 于是 `Integer → Float` 转型失败抛 `ClassCastException`；
- 这行代码在 `MainActivity.onCreate` 里，异常直接把**整个界面启动**带崩 —— 就是你看到的「点图标闪一下就没」。

**跟通知图标无关、跟小组件无关** —— 这就是为什么 v3.9.4 的修复没用。之前几版一直在错误的方向上修，这次凭日志一击命中。

## 这个「整数倍速」是怎么来的

追到了源头：**恢复备份的时候**。

`BackupRestore.restoreSettings()` 里，对备份包中的数值有个判断：只要是 `Integer` 或 `Long`，就一律 `putInt`。而如果你备份文件里的 `speed_global` 恰好是个**整数**（比如 1 而非 1.0），它就被存成了 int。之后 App 一读 float —— 必崩。

时间线也吻合：
- 你大概是**某次恢复过备份**之后开始闪退的；
- 覆盖安装不会清掉这个坏值，所以**装一次崩一次**，一直好不了；
- 卸载重装会清掉 SharedPreferences —— 所以我们上一轮才怀疑「卸载重装试试」。

## 本版修复内容（3 项）

### 1. 宽容读取 + 自愈（核心）

`Settings.speed()` 不再用会崩的 `getFloat()`，改为**读出原始对象再转**：

```java
Object raw = SP.getAll().get("speed_global");
if (raw instanceof Number) v = ((Number) raw).floatValue();
else if (raw instanceof String) v = Float.parseFloat(...);
// 若历史值是坏类型，顺手写回正确的 float（自愈）
if (!(raw instanceof Float)) setSpeed(v);
```

**效果**：无论历史存的是 整数 / 长整数 / 浮点 / 字符串，都能正确读出倍速；并且**首次启动就自动把坏值改写成正确类型**。

> 🎯 **升级后不用卸载重装，装上 v3.9.6 直接打开即好** —— 自愈逻辑会在第一次读取时修掉那个整数。

### 2. 堵住坏值的来源

`BackupRestore.restoreSettings()` 增加「浮点设置项」名单（目前是 `speed_global`），命中名单的键**强制按 float 写回**，不再走 `putInt` 分支。**以后恢复备份不会再把倍速写成整数。**

### 3. 倍速范围兜底

读取后校验：不在 `0.5 ~ 3.0` 区间（比如被写成了 0、负数、超大值）一律回落到 **1.0 倍速**，异常值不再影响启动。

## 遗留保障（沿用 v3.9.5）

- **初始化全隔离**：`App.onCreate` 里每一步都独立 try-catch，单点失败不再让整个 App 打不开；
- **崩溃日志必留**：处理器挂在启动第一行，且双写内部 + `/sdcard/Android/data/com.tingshu.app/files/crash.log`。这次能定位，就是靠它。

---

## 升级提示

1. **直接覆盖安装即可**，不用卸载（v3.9.6 会自动修掉你手机里的坏值）。
2. 装好后**第一次打开时**，`speed_global` 会被自愈为正确的浮点值；如果你之前设过倍速，可能需要在播放页**重新调一次**倍速（万一自愈时回落到了 1.0）。
3. 若仍遇到任何闪退，`/sdcard/Android/data/com.tingshu.app/files/crash.log` 会记录下来，发我即可。
