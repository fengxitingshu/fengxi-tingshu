# v3.9.10 更新说明（versionCode 62）

## ★ 修复：聚合源 jar 导入失败

v3.9.9 导入 `sources_by_agg.jar` 等原版「我的听书」格式插件时报
「jar 里没有找到可用的书源」。

### 根因

插件加载器枚举 dex 类名靠反射读取 `DexClassLoader` 内部的
`pathList → dexElements → dexFile` 字段链。**Android 10 之后该字段
被移除（改为 cookie）**，枚举静默返回空表 → 插件入口 `SourceEntry`
永远找不到 → 导入失败。已有 jar 插件不受影响是因为它们走
MANIFEST 入口（不依赖类名枚举）。

### 修复

1. 类名枚举改为**直接解析 jar 内 classes.dex 的字符串池/类型表**
   （纯 Java 实现，零系统内部 API 依赖，任何 Android 版本可用）；
2. 顺带兼容「zip 套 jar」双层导入（源作者常把 jar 再包一层 zip）；
3. 已在沙箱 JVM 用真实 `sources_by_agg.jar` 实测：207 个类全部解析
   出来，`SourceEntry` 命中。
