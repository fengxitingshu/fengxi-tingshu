# 枫兮听书 v4.7.1 更新说明（2026-10-25）

> versionCode 116 · 覆盖安装数据不丢（签名一致）

## 本版修复

### 1. 盘内书「播放失败，15 秒后自动停止」
- **根因**：盘内扫描出的书，章节信息编码格式为
  `平台|__disk__|书名|文件id|token`，但取直链时按固定位置拆字段，
  把**书名当成了文件 id**、把文件 id 当成了 token——整体错位一位，
  网盘直链接口必然失败。
- **修复**：改为从尾部取字段（最后一段 = token、倒数第二段 = 文件 id），
  中间拼回完整 share 信息，兼容旧分享链接格式。

### 2. 盘内书「不能选集」
- **根因**：章节缓存「写入」和「读取」两边各算各的 key，算出来的
  书 id 对不上（写入是 `disk___disk___书名`，读取只用 `书名`），
  详情/选集页永远拿到空列表。
- **修复**：统一由同一个方法生成书 id，写入/读取/续播三处完全一致。

### 3. 好消息：升级后不用重新扫描
- v4.7.0 播放时已经把章节表缓存到本机（只是读错了 key），本版修正后
  **直接读旧缓存即可**——装完 4.7.1 打开网盘书架直接点播放/选集就行。
- 仅当你之前手动清过缓存时，才需要重新「扫描盘内书」一次。

## 关于「分享链接解析没反应」
本版重点修的是盘内书播放链路（上面两个 bug 就是「点播放没反应/播放失败」的元凶）。
如果升级后**粘贴分享链接点解析**仍然毫无弹窗，请把当时的提示文字（或截图）发来，
那条链路已有失败必弹提示，拿到具体报错就能定位。

## 安装
- 覆盖安装即可，书源/Cookie/缓存全部保留。
- 装好后到 设置 → 关于 确认版本号为 **4.7.1 (116)**。
