# v3.9.9 更新说明（versionCode 61）

## ★ 新功能：支持 eprendre「我的听书」格式的聚合源插件

本次更新让枫兮听书可以直接导入开源听书生态（GitHub: eprendre/tingshu）的
自定义源 jar 包——包括用户提供的 `sources_by_agg.jar` 聚合包，内含
**番茄听书、博看有声、B 站有声、酷我听、懒人听书、蜻蜓 FM、喜马拉雅（部分需登录）、
网易云、评书、电台** 等 20+ 个源。

### 使用方法

1. 把 jar 包放到手机目录：
   `/sdcard/Android/data/com.tingshu.app/files/jars/`
   （或在 App 内「源管理」用导入插件功能选择该 jar 文件）
2. 重启 App，源管理里就会出现聚合包里的全部源。
3. 直接搜索、看详情、播放即可。番茄源无需登录（内部自动换取接口 token）。

### 宿主兼容层本次补齐的部分

| 组件 | 说明 |
|------|------|
| `AudioUrlDirectExtractor` | 直链取链器（博看有声使用）：章节地址即音频地址 |
| Fuel 网络库最小实现 | `Fuel` / `Request` / `FuelJson` / `responseJson` / `Result`——B 站、博看声用的 JSON 请求通道 |
| okhttp 4.10 + okio 3.0 | 打包进 APK 并保持原名（插件按名链接 okhttp 内部 API） |
| R8 保名规则 | `okhttp3.**` / `okio.**` / `kittinunf.**` 全部 keep |

### 验证结论

对上传的 `sources_by_agg.jar` 做了字节码级核对：

- jar 引用的全部 65 个外部类中，除 Android 系统自带的 `javax.crypto` / `org.json`
  外，其余**全部在 APK dex 中且类名未被混淆**；
- jar 直接链接的关键成员逐一抽查通过：
  `TingShu.search/getBookDetailInfo(+\$default)`、`Book` 全字段与 5 参构造、
  `BookDetail` 6 参构造、`Episode` 2 参构造、`AudioUrlDirectExtractor.INSTANCE`、
  `Fuel.INSTANCE`、`DefaultImpls.get$default`、`FuelJsonKt.responseJson`。

### 已知边界

- 需要 WebView 嗅探/渲染取链的源（如 Ting29）暂不可用（该提取器宿主未实现）；
- 需要扫码/网页登录的源（喜马拉雅 VIP 内容、蜻蜓 VIP）免费内容可听，VIP 需登录的暂不支持；
- 插件源的网络请求耗时取决于站点，搜索慢属正常。

> 合规提醒：插件源内容来自各第三方站点，仅供个人学习与设备迁移使用，请勿用于商业用途。
