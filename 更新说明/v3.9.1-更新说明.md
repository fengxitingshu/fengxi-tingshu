# 枫兮听书 v3.9.1 更新说明

> 主题：修复一批"功能消失"与"点了没反应"，并把小组件从白卡状态救回来。
> 共 9 项，全部来自实际使用反馈（机型 iQOO 15 / originOS 7 / Android 16）。

---

## 一、小组件白卡修复（最重要）

**现象**：桌面小组件显示为一张**系统默认白卡**，进度位置退化成一个**转圈的小圆点**。

**根因**：v3.9.0 的白板重写用了自绘资源——背景 layer-list+gradient、进度条 progressDrawable、圆形按钮背板、角标 pill、状态点，以及 `ProgressBar` 的 `style="?android:attr/progressBarStyleHorizontal"`。**桌面进程在解析这些自绘资源与主题属性时失败，整张卡片膨胀不出来**，系统回落到默认白卡。这正是 3.8.4 / 3.8.5 已经踩过并修掉、v3.9.0 又踩回去的坑。

**本版做法（回归"桌面零解析"稳妥方案）**：

- 底色直接在 XML 里写**固定颜色**，不引任何 drawable
- **取消 ProgressBar**，改成 20 个格子由代码逐格上色；同一批格子同时承担点击跳转
- 图标只用系统自带位图，不用自绘矢量
- 角标和状态点改用**文字**（`●`、`2×`、`⏱ 23分`）+ 固定色背景
- 绘制过程**一段一段独立 try**：任何一段出问题只丢那一段，不会整块变白
- 八个自绘 drawable 文件已删除，防止以后再被误用

功能与点击通路不变：可点进度条（20 格）、四键控制、点封面进 App。

## 二、选集菜单支持返回键关闭

选集弹层是独立于普通弹窗的全屏容器，之前返回键完全不认识它——打开选集后按返回，直接去关全屏播放页或退回上一级，而选集还挂在屏幕上。现在返回键最先关它。

## 三、首页返回提示退出 + 连按两次直接退出

原来在首页按返回**毫无反应**：原生用 `evaluateJavascript`（异步、拿不到返回值）之后又无条件返回 true，前端的返回值被丢弃了。

现在：第一次按 → 弹「确定要退出枫兮听书吗？」；确认框还开着时**再按一次直接退出**（不用去点按钮）；点取消或遮罩则继续用。退出只关界面，不杀进程——后台还在播的话通知栏照常。

## 四、本地书源支持自定义目录

- 自定义源页显示**当前扫描范围**，默认"全部目录"
- 点「选择文件夹」用系统目录选择器（SAF）指定一个文件夹，只扫该目录（含子目录）
- 可随时「恢复全部目录」
- 少数 ROM 的目录 ID 还原不出真实路径时，**退化成手动输入路径**，而不是干巴巴报一句失败

## 五、源管理分组内「批量管理」

顶栏新增「批量」按钮，**显式进入**多选态（不用长按进入——那是 v3.7.14 移除多选的原因：长按和选择会打架）：

- 逐行勾选，底部工具条：全选 / 反选 / 启用 / 停用 / 删除 / 完成
- 批量启用停用只弹一次汇总提示，不逐条刷屏
- 返回键先退出批量态，再退回上一级
- 内置源组不给删除（与既有规则一致）

## 六、Python（.py）源修复与排障

修掉两个真实缺陷：

1. **并发二次启动**：后台正在启动解释器时，导入流程会再进一次 `Python.start()`（Chaquopy 不幂等），抛异常后表现为"Python 运行时不可用"，真正原因被吞在异常里。现在改为**等待后台启动完成**
2. **失败后永久判死**：一次启动失败后整个进程内再也不会有 Python 源。现在允许**有限次重试**
3. **就绪回调时序**：`TRIED` 在启动一开始就被置位，导致拿着 `ok=false` 空跑一次回调、错过真正的就绪通知。条件已收紧为"已启动结束"

另外在「Python 源」分组加了两个排障按钮：**重新加载**（手工催一次补登记）与**运行自检**（显示 Python 版本、sys.path、每个关键模块的导入结果，缺 lxml / Crypto 之类一眼可见）。

## 七、关于页与状态栏图标统一为应用图标

- **关于页**：原来的 🎵 emoji 换成**真实的应用图标位图**，与桌面图标一致
- **状态栏**：通知小图标从系统 `ic_media_play` 换成与软件同款的「翻开的书」单色剪影（Android 5.0+ 会强制单色化，所以用纯白实心剪影，上彩色会糊成白块）

## 八、状态栏控制按钮锐化

上一集 / 播放暂停 / 下一集 / 停止原来用的是 `android.R.drawable.ic_media_*`——系统框架位图**只有 mdpi 一张**，在 xxhdpi/xxxhdpi 手机上被拉伸，边缘发糊带锯齿。现在全部改为**自绘矢量图标**，按屏幕密度实时光栅化，任何密度下都锐利。

顺带把「停止」从 ✕ 改成实心方块——✕ 在通知栏里容易被理解成"关掉这条通知"而不是"停止播放"。

## 九、备份文件恢复失败修复

**根因**：选备份文件时**没有申请持久化读取授权**（`takePersistableUriPermission`）。用户选完文件会先看确认框再点恢复，这中间 Activity 完全可能被系统回收重建，临时授权随 Activity 一起没了，于是恢复时 `openInputStream` 直接抛 `SecurityException`——表现就是"点了恢复，提示失败"，而且怎么重试都一样。

同时两处改进：

- 恢复前的**自动留底失败不再中止恢复**（原来安全网一挂就整次取消，用户拿着好好的备份包却永远恢复不了），降级为告警，照样恢复并如实告知"没留底"
- 权限类错误给出**可操作的提示**："没有该备份文件的读取权限了，请重新选择一次备份文件再恢复"
