# v4.11.0 更新说明（2026-10-26）

本版是一个「内容方向」的里程碑：在保持**空壳播放工具**定位的前提下，加入了两类**完全合规**的内置内容源，并补齐了上架所需的合规文档。

## 新增

### 1. 播客电台（内置源）
- 通用播客 RSS 订阅器：播客本身就是公开发布、开放订阅的内容，完全合规。
- 内置 9 档精选节目（均为制作方公布的 RSS 地址，2026-10 实测可用）：
  - 声东击西 / 声动早咖啡（声动活泼）
  - 少数派播客 / 字谈字畅 / 无人知晓 / 啤酒事务局 / 天方乐谈 / 周末变奏 / 大内密谈
- **支持自行添加任意播客 RSS**：首页 → 播客电台 → 管理订阅 → 粘贴地址（添加前自动验证一次并取节目名），支持删除。
- 单集带时长显示；节目封面自动抓取。

### 2. 公版书（内置源）
- 四大名著（红楼梦 597 集 / 三国演义 248 集 / 水浒传 214 集 / 西游记 196 集）、史记、汉书、小学生必背古诗词 —— 均为**公版著作 + 作者本人公开发布的免费朗读版**（白云出岫系列，喜马拉雅官方 RSS 订阅地址，音频走公开 CDN）。
- 回目按集数正序排列（第 1 回在最前），支持中文数字集数解析。
- 只收录了官方开放 RSS 的专辑；想加更多公版书，在「播客电台 → 管理订阅」里粘贴对应专辑 RSS 即可。

> 备注：LibriVox 的公版朗读虽好，但音频托管在 archive.org（国内网络无法访问），故未内置；已验证喜马拉雅专辑 RSS 通路国内可用。

### 3. 合规三件套
- 新增「用户协议」「隐私政策」「内容合规声明」三个页面（关于页 → 协议与合规，纯离线可读）。
- 隐私政策核心：**不注册、不登录、不上传，无统计/广告 SDK，数据仅存本机**。
- 首次启动展示合规摘要弹窗，需点「同意并继续」；不同意则退出。
- 内容合规声明含**权利人通知通道**（避风港机制的基础）。

## 技术说明
- 新增 `RssParser`：通用 RSS 2.0 / Atom 解析器（XmlPullParser，itunes: 字段本地名匹配，enclosure 直链，itunes:episode 集数）。
- 新增 `PodcastSource` / `GongBanSource`：两个 BrowsableSource，注册进 SourceRegistry（与 v2.4「去内置盗版源」原则不冲突 —— 这两类内容公开可自由分发）。
- Bridge 新增：`podcastSubs / podcastAdd / podcastDel / exitApp`；订阅存 Settings（JSON）。

## 定位重申
本 App 的商业化路线 = **工具价值（播放体验 / 本地库 / 网盘自有内容）+ 合规内容（播客 / 公版书）**，不碰任何版权灰区内容。
