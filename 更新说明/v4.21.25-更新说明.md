# 枫兮听书 v4.21.25 更新说明

## 修复：百度网盘播放「只有 20~30 秒 / 又慢又断」

### 问题定位（来自 v4.21.24 的播放日志）

- 百度对非会员下载的限速模式是：**给一小波流量（约 0.5~4MB）→ 长时间断流 → 再给一小波**
- v4.21.24 的「3 次续传」额度在几秒内就被耗光，播放器内核等不到数据，自己把连接掐了（日志里的 Broken pipe）
- 播放器只收到残段，所以**时长只显示 26 秒 / 17 秒**，且「自救②」每次重播都从 0 重新下载，又慢又断

### 本版方案：本地缓存文件中继（治本）

- 代理改为**后台死磕式下载**：把整集文件下载到本地缓存（断流自动重连续传，最多 40 次、间隔 1.5 秒），上游爱断就断，下满为止
- 播放器改为**从本地缓存文件流式取数**：缓存追上了就无缝喂，没追上就短暂缓冲等待——对播放器是一条完整的连续流
- 响应头携带**正确的文件总大小**，时长、进度条、拖动全部恢复正常
- 同一集重播（自救②）**直接复用已下载部分**，不再从 0 开始
- 缓存最多保留 3 集（LRU 自动清理），不占多余空间

### 说明

- 非会员首次播放某集时，开头的缓冲时间取决于百度限速松紧（通常几秒到几十秒），这是平台待遇，App 侧已把体验做到极限
- 播完一集的剩余部分会继续在后台下完，下一集的转存+取链照常

### 其他

- 功能诊断、双栏搜索、多选导入等 v4.21.19~24 的功能不受影响
