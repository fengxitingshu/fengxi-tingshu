# 枫兮听书 v3.9.0 更新说明

> 主题：小组件白板重写 + 自定义源（本地书源 / 网盘接口）+ 常驻定时关闭。
> 四项用户点名需求全部落地：小组件推倒重做、定时关闭支持可选时段、
> 选集页已收听标记、书源管理新增「自定义源」。

---

## 一、桌面小组件白板重写（全新设计）

旧版是半透明中性灰卡，深色壁纸上和背景糊在一起、白字对比度不足；
控制键是裸图标，小尺寸下有效点击区只有中间一小块。本版**推倒重做**：

- **深色渐变卡片**：不透明深蓝灰斜向渐变（#1B2133 → #2C3550）+ 顶部窄高光带 + 细描边，任意壁纸上都是同一块"深色玻璃卡"，白字对比度稳定
- **封面右上角状态点**：播放中=暖色圆点、暂停=灰点，锁屏外也能一眼看到播没播
- **四键圆形背板**：上一集 / 下一集 / 停止坐上半透明玻璃圆钮，有效点击区扩大一倍；**播放/暂停用主题色渐变圆突出**（#E8503A → #FF7A5C），视觉焦点即主功能
- **进度条加粗到 6dp**，已播部分用暖色渐变（#FFD9A0 → #FF8A6B），仍支持 20 格点击跳转（每格 5%）
- **两个新角标**：当前倍速（≠1.0 才显示，如「2×」）、定时关闭剩余（「⏱ 23分」/「⏱ 停表」）

功能与点击通路不变：四键走通知栏同一条播放服务通路，点封面/书名进 App。

## 二、新增「自定义源」（书源管理置顶分组）

书源管理一级页置顶新增「自定义源」组，内含两块能力，**都在既有播放管线内**——入队后自动下一集、历史续播、通知栏、桌面小组件、播放失败换源全部自动生效，不需要任何额外适配。

### 2.1 本地书源（播放本机音频）

- 扫描本机存储里的音频文件（音乐 / 听书 App 下载的文件夹都能识别），**按所在文件夹自动分成一本书**
- 文件名即章节名，`001 < 002 < 010` 自然排序，不会出现"第 10 集排在第 2 集前面"
- `file://` 直接本地播放，不耗流量；需要存储权限时会引导授权，批了自动重扫
- 短录音/铃声自动过滤（时长 ≥ 60 秒或标记为音乐才收）

### 2.2 主流网盘接口（六个平台）

阿里云盘、百度网盘、夸克网盘、天翼云盘、115网盘、UC网盘：

- 每平台一行：**已配置/未配置徽章** + 启用开关 + 配置 Cookie + 粘贴分享链接解析
- 解析结果列出文件清单（名称 + 大小），默认全选，也可勾选后「播放选中」
- **Cookie 只存本机**，直链每次播放时现取、不落库（网盘直链有时效）
- 各平台独立隔离：某个平台接口改版只影响它自己，错误信息如实给出（Cookie 失效 / 接口改版 / 链接无效），不静默失败
- 阿里云盘走官方 share_token 机制，公开分享一般无需配置 Cookie

## 三、定时关闭升级：进程级常驻 + 可选时段

- **常驻**：倒计时从"播放页里的网页计时器"改为 **App 进程级单例**，每秒由主线程轮询。退后台、锁屏、甚至进程被杀后重启，都会自动恢复剩余时间，到点照常暂停（系统 Toast 提示）
- **可选时段**：播放页「定时」菜单里新增时段选择（每 15 分钟一档，支持跨午夜如 22:00–06:00）。**时段内倒计时才递减；时段外自动停表、剩余时间保留，进入时段后继续**
- 适合"只想睡前听、不希望白天也计时"：设 30 分钟 + 时段 22:00–06:00，白天开着不影响，夜里才真正倒数

## 四、选集页「已收听」绿色小对勾

- 听过的集（进度表里有记录的）在章节列表里显示**绿色小对勾**，追长书时一眼看到哪集听过
- 数据零新增存储：直接复用每集偏移记录（1 基），开播即时打勾，不等网络往返
- 选集弹层与详情页章节列表同时生效

## 安装说明

- 直接覆盖安装，收藏、历史、进度、设置、书源都不会丢。
- 旧小组件**建议移除后重新添加**一次（新布局结构，旧实例在部分桌面可能不刷新）。
- 网盘接口按平台配置 Cookie 后即可用；不配置也能解析阿里云盘公开分享。

## 兼容性

- 本地书源扫描权限：Android 13+ 用 `READ_MEDIA_AUDIO`，12 及以下用 `READ_EXTERNAL_STORAGE`
- 网盘接口为各平台公开/半公开 Web 接口，平台改版可能导致个别平台失效——失效时会有明确错误提示，不影响其它平台与既有书源
