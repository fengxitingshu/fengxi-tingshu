# 枫兮听书 v4.2.0 更新说明

> 2026-10-25 · versionCode 109

## 修复

### 1. 首页返回键改为「双击退出」
- 去掉了「确定要退出枫兮听书吗？」确认弹框（多此一举）
- 现在单击返回键 → 底部提示「再按一次返回桌面」
- **2.2 秒内连按两次返回键 → 直接返回桌面**
- 后台播放不受影响：退出只关界面，通知栏照常可控

### 2. 本地书源权限不足自动申请
- 点「扫描本机音频」时若没有存储权限，**自动弹出系统授权框**
- 不再需要「先按去授权、授权完再手动重扫」两步
- 授权完成自动重新扫描（3 秒节流，不会连环弹窗）

### 3. 本地扫描结果持久化
- **重开 App 不用重新扫描**：上次扫到的本地书直接可用
- 扫描结果落盘保存（书列表 + 文件清单），进程重启后自动恢复
- 改过「扫描范围」时会作废旧缓存并重新扫描（防止书列表错乱）

## 新增

### 4. 网盘登录（替代手动粘贴 Cookie）
| 平台 | 新方式 | 说明 |
|---|---|---|
| 115 网盘 | **扫码登录** | 弹窗显示二维码，115 App 扫一下自动拿 Cookie |
| 天翼云盘 | **密码登录** | 输手机号 + 密码即可，密码走官方 RSA 加密通道 |
| 百度/阿里/夸克/UC | 粘贴 Cookie（保留） | 无公开登录接口，硬做会天天失效 |

- 115 扫码：二维码过期/超时有明确提示，关闭弹窗自动停止轮询
- 天翼密码登录：触发验证码时明确提示改用 Cookie，不静默失败
- 登录成功 Cookie 自动保存，与手动粘贴等效
