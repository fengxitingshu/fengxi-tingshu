# 枫兮听书 v3.8.5 更新说明

> 主题：把桌面小组件做到"哪台手机都能用"，并理顺返回键。
> 小组件前几版在部分桌面显示空白 / 圆圈，这一版换了实现思路彻底解决。

---

## 一、桌面小组件推倒重写（解决"多台手机全部用不了"）

前几版小组件的空白，根因是**桌面在绘制卡片时解析不了我们自绘的那些样式**——背景一旦加载失败就回落到系统白底，而字和图都是白的，看上去就是一张白卡片（进度条还会退化成一个小圆圈）。

本版把所有"需要桌面去解析"的自绘样式全部去掉：

- 底色改用**固定颜色**（不再依赖桌面解析主题 / 渐变）
- 进度条改成 **20 个小格子直接上色**（可点，每格 5%，点哪跳哪）
- 封面**直接传图片**（普通位图）
- 只保留系统自带图标，不用自绘矢量
- 绘制过程**一段一段独立 try**：任何一段出问题也只丢那一段的功能，不会整块变空白

另外新增**小组件诊断日志**：设置 → 小组件诊断，可查看添加 / 刷新 / 移除事件，出问题时截图反馈即可定位。

## 二、返回键逻辑理顺

以前返回键没真正用上前端的处理结果，出现"打开了更多菜单或倍速面板，按返回却在切页 / 退出"。

现在返回键**一次收一层**：关弹窗 → 关长按菜单 → 折叠倍速/音量面板 → 退出全屏播放页 → 退回上一级 → 回首页。

## 三、首页返回退出确认

在首页按返回会弹「确定要退出吗？」；点「退出」才关闭 App。若 2.5 秒内连按两次返回则直接退出，不用等弹窗。
