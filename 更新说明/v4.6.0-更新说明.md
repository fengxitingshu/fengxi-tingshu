# 枫兮听书 v4.6.0 更新说明

> 2026-10-25 · versionCode 114

## 修复

### 盘内书播放串到别的资源
- 根因：书 id 用书名原文生成，书名含「/」等字符时不同书会**互相冲突**
  （「三体/上」「三体/下」撞成同一个 id），历史/续播/直链缓存跟着串书
- 已修：id 生成做字符消毒；并且**网盘书播放只走网盘直链**，绝不自动换到
  其他源——取链失败直接明确报错，不会再播到互联网上的同名资源

### 分享链接解析「没反应」
- 解析失败原来只把错误写在卡片底部，看不到 → 现在失败立即弹错误提示
- 45 秒无响应自动解除「解析中」并提示超时

## 新增 / 调整

### 首页左上角下拉新增「网盘源」分组
- 已启用的网盘源现在出现在首页源下拉里，可以像书源一样当首页源
- 点进去就是**该网盘的有声书书架**（盘内扫描结果），点书即播

### 界面调整
- 首页顶栏「1列」分列按钮移除，列数选择移到 **设置 → 首页列数**
- 自定义源（本地书源 + 网盘接口）入口也移到设置页
- 盘内扫描书列表重新排版：书名 + 集数 + 播放按钮一行一本，不再错乱
