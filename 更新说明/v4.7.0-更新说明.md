# 枫兮听书 v4.7.0 更新说明

> 2026-10-25 · versionCode 115

## 修复

### 盘内书「不能选集」
- 根因：盘内书的章节表只存在于播放那一刻的内存里，详情/选集走的
  「详情接口」对盘内书返回空 → 选集列表永远是空的
- 已修：播放时把整份章节表**缓存落盘**，详情页/选集弹层/历史续播/
  重启 App 后都有完整集数

### 分享解析「没反应」
- 解析「成功」但结果为空 / 全是文件夹时原来**没有任何提示**
- 现在三种结果都有明确弹窗：N 个音频文件已全选 / 没有音频文件 / 链接失效

## 重要提醒

之前（v4.5.0 时代）播串过书的播放记录是脏数据，升级后建议：
**设置 → 一键清理缓存**，然后到网盘书架重新扫描、重新播放一次。
之后每一本的记录都是独立的，不会再串。
