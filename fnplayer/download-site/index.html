⬇ 下载安装包
安装步骤（vivo 等手机）：
  1. 点上面按钮下载；若提示「该安装包可能有风险」，选「仍要下载 / 继续」
  2. 下载完成后点浏览器的「下载完成」提示，或到「文件管理 → 下载」里点开 apk
  3. 弹出「未知来源应用」时允许本浏览器安装，然后点「安装」
  4. 打开 App → 「我的 → 订阅 / 源管理」导入你自己的源即可使用
v2.25 更新：① 修真机闪退——不再加载第三方爬虫包里的 native 加密壳（这类壳 ABI 不匹配会直接杀进程），改为明确提示「不支持」；源清单改为摘要，避免大配置把 WebView 撑爆。② 修「很多源解析不了」：纯爬虫站线路不再被误判为解析失败并整体回滚；配置里的相对 spider.jar / file:// ext 自动补全并按需下载；type=0 的 XML 采集站现在能读；JSON 截取改括号平衡，尾部带脚本的配置也能解析。③ 「我的 → 崩溃日志」可一键复制堆栈，闪退时能直接定位。④ 版本号、下载页与更新清单同步；签名证书沿用原证书，可直接覆盖安装。
本 App 不内置任何影视资源，内容全部来自你自己导入的源。
