安装步骤（vivo 等手机）：
  1. 点上面按钮，浏览器开始下载（若提示「该安装包可能有风险」，选「仍要下载 / 继续」）
  2. 下载完成后，点浏览器的「下载完成」提示，或到「文件管理 → 下载」里找到 apk 点开
  3. 弹出「未知来源应用」时，允许本浏览器安装应用，然后点「安装」
  4. 装好后打开 App → 「设置」填飞牛地址 → 跑一次「连接诊断」
v2.13 更新：① 源选择全面改版（参考成熟影视 App）：首页左上角与源管理点开的是居中弹窗「请选择首页数据源」，带搜索框与全宽按钮列表，当前源高亮；直播页源选择同样改居中弹窗（列表 + 图标 + 删除 + 添加都在弹窗内）。② 内置 TVBox spider 运行时：爬虫源（csp_ 类名 + jar）可直接播放——自动下载配置里的爬虫 jar 并加载，首页分类/影片列表/详情/选集/播放全链路打通；需解析的集自动请求解析页嗅探直链；源管理与首页弹窗里的爬虫源都能选为当前源。③ 配置解析容错加强：多 UA 依次重试（部分配置站按 UA 拦截）、GBK 编码自动嗅探、自动截取 JSON 本体（配置页前后带广告文本也能解析）、type=1 站点的相对接口地址自动按配置地址补全（不再报「无效源」）。
v2.12 更新：① 首页源选择器从顶栏移到内容区左上角独占一行（不再和居中标题挤压）；② TVBox 接口源全格式收录：csp_ 类名爬虫站、jar/js 接口站全部列出（存「爬虫源」分类+首页下拉灰显，点击明确提示暂不支持），不再报「无效源」；③ 名称带「短剧」的资源站自动对接短剧页（读取其「短剧」分类，支持翻页）；④ 直播页下拉里的源只显示名称（隐藏地址），有 logo 显示图标、无 logo 显示首字徽标；频道列表同样支持 tvg-logo 图标。
v2.11 更新：① 顶栏源选择器固定到左上角（贴边、限宽省略，不再挤在标题旁）；② TVBox 线路里的爬虫源不再直接跳过：收进源管理「爬虫源」分类并在首页下拉里灰显列出（需 spider 运行时暂不支持播放，点击有明确提示），重复解析自动去重；③ 修复直播页下拉不显示直播源（下拉被误绑成影视源列表）；④ 设置 → 通用 新增「主题模式」：跟随系统 / 亮色 / 暗色手动切换；⑤ 直播源无可播频道时提示具体原因（如全部是网页链接）。
v2.10 更新：① 下拉菜单修复（v2.9 样式规则被截断导致无底色）：加不透明底色/边框/圆角，菜单与按钮左对齐并限宽，长名称/长地址单行省略不再撑爆；② TVBox 选线路改异步：原来在 WebView 线程同步下载解析，网络慢时整个界面假死（多次操作卡死根因），现在后台解析+自动刷新首页/直播下拉，选线路后自动选中第一个资源站、直播页自动加载新直播源；③ 修复 v2.9 短剧页闪退（进度条计时器在初始化前启动）。
v2.9 更新：① TVBox 线路解析修复：线路配置常用中文域名（饭太硬.net 等），Java 不支持需转 punycode，现已自动转换（含中文路径）；② 短剧竖滑修复（手势不响应根因）+ 画面比例适配（不再拉伸变形）+ 新增可拖动播放进度条与时间显示；③ 短剧列表下滑自动加载更多（配套新版红果源脚本 v2，分类页每页 24 部可翻 30+ 页，下载新脚本 hongguo-v2.js 重新导入 生效）；④ 播放集数限制说明：红果官网仅免费试看集提供直链，付费集 App 端会明确提示（第 X 集起无地址）；⑤ 移除已失效的连接诊断功能（内嵌网页浏览入口移至设置页）；⑥ 主页下拉菜单限高防溢出（超高自动滚动）；⑦ 减小播放器左右刘海/R角避让宽度。
