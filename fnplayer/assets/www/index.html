关于
枫兮影视 v2.25 · 多源影视播放器：NAS 源 / 资源站 / 爬虫源 / 短剧源，支持 TVBox 线路订阅、加密配置解码、关键词搜索与观看历史。
本 App 不内置任何影视资源，内容全部来自你自导入的源。
导入源
支持「阅读 / prelude」式 JS 源脚本（zip 内含 manifest.json）。导入后自动归入分类并接入对应栏目（短剧源 → 短剧栏）。
仓库配置会存为「TVBox 源」并弹出「选择线路」；单配置直接解析入库。选定线路后：CMS 资源站进首页源列表（自动选中第一个站）、直播源进直播弹窗、爬虫源走内置 spider 运行时直接播放（重复解析自动去重）。解析失败会给出具体原因（地址被拦 / 编码不对 / 格式不支持）。
