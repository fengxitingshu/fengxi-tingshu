安装步骤

  1. 点上面的下载按钮，浏览器把 APK 存进「下载」目录（提示风险时选「仍要下载」）
  2. 到「文件管理 → 下载」找到 APK，点开用「包安装程序」安装
  3. 弹出「未知来源」时允许本浏览器安装应用
  4. 影视：打开后填飞牛地址或导入 TVBox 订阅；听书：登录网盘后粘贴分享链接即可
安装提示：两个包都是 targetSdk 28（为放行局域网明文 HTTP），新系统可能提示「为旧版 Android 打造」，属正常，继续安装即可。若点 APK 被别的 App 抢开，去 设置 → 应用管理 → 找到抢注 .apk 的 App → 清除默认值。
