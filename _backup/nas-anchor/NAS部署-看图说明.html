不用懂 Docker、不用装 nginx、不用配反代、不用填 NAS 路径

我这边推不进你的 NAS，
所以让 NAS 自己来拿，
它拿到后顺手把下载页也生成好。

照着做这 3 步

1

把 2 个文件放进 NAS

解压 FX-NAS锚点-傻瓜版.zip，在飞牛「文件管理」里随便新建个文件夹（比如 fx-download），把 anchor.py 和 docker-compose.yml 传进去。

fx-download/ ├── anchor.py ← 同步小程序 ├── docker-compose.yml ← 启动配置 └── web/ ← 不用建，运行时自动出现
2

在飞牛里点一下启动

Docker → Compose → 新增，项目名填 fx-download，路径选第 1 步那个文件夹，点「确定 / 启动」。第一次要拉镜像，等 1～2 分钟。

如果界面是让你粘贴 YAML 文字而不是选文件夹：先把 anchor.py 放进那个文件夹，再把 docker-compose.yml 的内容整段粘进去，其余一样。
3

用浏览器打开

手机或电脑连家里 WiFi，访问下面这个地址。内网 IP 在飞牛「设置 → 网络」里看。

http://192.168.1.20:8099/ 把 192.168.1.20 换成你 NAS 的实际内网 IP

第一次可能显示「正在同步…」，等几秒刷新；看到绿色 ⬇ 下载安装包 按钮就完成了。

没有第 4 步。这个 :8099 就是你要的固定 IP 下载页，以后一直是它。装到手机/车机时，在同一 WiFi 下打开这个地址即可。

以后出新版本

我这边构建完新 APK 会刷新一次清单 → 你的 NAS 最多 60 秒后自动下载替换 → 你刷新页面就是最新版。你什么都不用做，地址也不变。

遇到这些别慌

现象怎么办
8099 被占用记事本打开 yml，把 "8099:8000" 左边改成 18099，重新部署
一直「正在同步…」Docker → 容器 → fx-download → 看日志；多半是 NAS 暂时连不上公网
显示「源暂不可达」正常降级，APK 照样能下，联网恢复后自动补同步
点 apk 被别的 App 抢开手机 设置 → 应用管理 → 找到抢注 .apk 的 App → 清除默认值
拉镜像慢 / 失败等几分钟重试，或在飞牛 Docker 设置里配镜像加速
已经按旧包折腾过不用回滚，两套互不影响；把旧容器停掉删掉即可
一个要提前知道的事：当前的更新源是会话级发布应用，不是永久服务器，将来可能失效。失效只影响「自动更新」，NAS 上已下载的 APK 和下载页照常可用，不会变砖。想长期稳定，把 manifest.json 和 apk 放到你自己的 GitHub / 对象存储，改 yml 里 SRC_MANIFEST 一行即可，锚点代码一行都不用动。
