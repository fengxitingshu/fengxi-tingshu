# 最简部署：3 步，不用懂 Docker

> **从哪拿这个包**：下载页「NAS 锚点 · 傻瓜版（推荐）」卡片里的第一个绿色按钮
> `⬇ 下载傻瓜版部署包`；旁边的「看图说明」是同款 3 步图解，可直接在浏览器打开。
> 保存下来就是 `FX-NAS锚点-傻瓜版.zip`（浏览器若存成 `.bin`，把后缀改成 `.zip` 即可）。

## 先说这套东西在干嘛（3 句话）

我这边（沙箱）**没法把文件推进你的 NAS** —— 你的域名只有 IPv6，我没有 IPv6 出口，连不进去。但你的 NAS 能出公网。所以反过来：放一个小程序在你 NAS 上，让它每 60 秒主动问我一次「有新版本吗」，有就自己下载、自己生成一个下载网页。

**你要的结果就是一个固定地址：`http://你NAS的内网IP:8099/`，打开就能下载安装。**

> 旧版那个包要接你已有的 nginx 站点、要填 `/vol1/1000/...` 路径、要配反代，太绕。
> **这个新包容器自带网页服务，上面那些全都不用管。**

---

## 第 1 步：把 2 个文件放进 NAS

1. 解压这个 zip，得到 3 个文件
2. 在飞牛「文件管理」里新建一个文件夹，名字随便，比如 `fx-download`
3. 把 **`anchor.py`** 和 **`docker-compose.yml`** 这 2 个文件传进去（本说明文件可以不传）
4. 记住这个文件夹在哪，下一步要选它

## 第 2 步：在飞牛里启动

1. 打开 **Docker → Compose → 新增**（有的版本叫「创建项目」）
2. 项目名称填 `fx-download`
3. **路径选第 1 步那个文件夹**
4. 点「确定 / 启动」，等它拉镜像（第一次约 1～2 分钟）

> 如果界面是让你**粘贴 YAML 内容**：先把 `anchor.py` 放进那个文件夹，再把 `docker-compose.yml` 里的文字整段粘进去，其余一样。

## 第 3 步：打开下载页

浏览器访问：

```
http://你NAS的内网IP:8099/
```

内网 IP 在飞牛「设置 → 网络」里看，形如 `192.168.1.20`。

- 第一次打开可能显示「正在同步…」，等几秒刷新即可
- 看到绿色按钮 **⬇ 下载安装包** 就成了

**没有第 4 步。** 不用装 nginx、不用配 Lucky 反代、不用填任何 NAS 绝对路径、不用给我账号密码。

---

## 以后出新版本怎么办

**你什么都不用做。** 我这边构建完新 APK 会刷新一次清单，你的 NAS 最多 60 秒后自动下载替换，刷新页面就是最新版。地址永远是 `:8099`。

---

## 可能遇到的几个情况

| 现象 | 怎么办 |
|---|---|
| 8099 被别的程序占了 | 用记事本打开 `docker-compose.yml`，把 `- "8099:8000"` 左边改成 `18099`，重新部署 |
| 一直是「正在同步…」 | Docker → 容器 → `fx-download` → 日志，看报什么；多半是 NAS 暂时连不上公网 |
| 页面显示「源暂不可达」 | **正常降级，APK 照样能下载**，联网恢复后会自动补同步 |
| 点 apk 被别的 App 抢开 | 手机：设置 → 应用管理 → 找到抢注 `.apk` 的 App → 清除默认值 |
| 拉镜像很慢 / 失败 | 等几分钟重试；或在飞牛 Docker 设置里配镜像加速 |
| 想用手机在外网也能打开 | 那是另一回事（需要公网 IPv4 或内网穿透）。**局域网内用 IP 最稳**，车机/手机连家里 WiFi 即可 |

## 进阶（不看也行）

- **换更新源**：`docker-compose.yml` 里 `SRC_MANIFEST` 那一行。当前是会话级发布应用，不是永久基础设施，长期建议换成你自己的 GitHub / 对象存储 / 静态站（把 `manifest.json` 和 apk 传上去，填 raw 地址即可），**锚点代码一行都不用改**。源失效只影响「自动更新」，已下载的 APK 和下载页照常可用，不会变砖。
- **想挂到自己域名下**（`https://你的域名/apk/`）：才需要 nginx / Lucky 那套，之前那个 4 文件的旧包就是干这个的。
- **不想用 Docker**：任何有 python3 的机器都能跑：
  ```bash
  export SRC_MANIFEST='https://…/manifest.json'
  export OUT_DIR=./web HTTP_PORT=8000 INTERVAL=60
  python3 -u anchor.py
  ```
- **安全边界**：锚点只做三件事——读清单、下载并校验 APK（MD5 + 大小，先写 `.part` 再原子替换）、生成静态页；不执行源端任何代码，文件名有白名单校验，不需要 root，只往 `web/` 目录写文件。
