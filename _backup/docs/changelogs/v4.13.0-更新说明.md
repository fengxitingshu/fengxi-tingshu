# v4.13.0 更新说明 —— 个人音频库（WebDAV）

> 一句话：**现在能直接播你自己 NAS / 家庭存储里的音频了。**
>
> 这是把 App 从「能听公开内容」推进到「能听你自己的内容」的一步：
> 播客和公版书别人也能听，但你 NAS 里那堆音频，只有这个 App 最方便播。
> 它同时是零版权风险的一块 —— App 不提供任何内容，播的全是你自己的文件。

## 一、怎么用

1. 更新后打开 App → 首页会多出一个源「**个人音频库**」
2. 点进这个源 → 分类条最后一项「**管理服务器**」
3. 填表保存：
   - **名称**：自取，随便起（如「家里 NAS」）
   - **WebDAV 地址**：见下面各家 NAS 的写法
   - **入口路径**：选填。进这个源后最先看到的那一层，比如 `有声书`
   - **账号 / 密码**：NAS 的登录账号；匿名访问可留空
   - **认证**：默认「自动」，一般不用改
4. 点「**测试连接并保存**」—— 会真的连一次，**连不通不会入库**，避免攒下一堆无效配置
5. 保存成功后回到源页面，就能看到这台服务器的分类 chip 了

> 如果你之前已经在「备份与恢复」里配过 WebDAV，可以直接点面板上的
> **「↓ 使用备份页已配置的那台」** 一键带入。

### 各家 NAS 的 WebDAV 地址

| 设备 / 服务 | 后台开启位置 | 地址通常长这样 |
|---|---|---|
| 群晖 DSM | 套件中心 → WebDAV Server | `http://192.168.1.10:5005/` |
| 威联通 QTS | 控制台 → WebDAV | `http://192.168.1.10:5006/` |
| 极空间 / 飞牛 | 系统设置 → WebDAV | `http://192.168.1.10:5005/dav/` |
| Alist / OpenList | 本机 WebDAV 服务 | `http://192.168.1.10:5244/dav/` |
| 坚果云 | 第三方授权 | `https://dav.jianguoyun.com/dav/` |

**IPv6 地址必须带方括号**，这是最容易卡住的一步：

```
http://[2001:db8::1]:5005/dav/
```

## 二、一个目录 = 一本书

进去之后看到的是你服务器上的目录结构：

- **子目录各成一本书**：目录名就是书名，点进去是该目录下的全部音频文件（= 章节）
- **本层若有散装音频**：额外给一本「▶ 本层音频（N 个文件）」，点开可整层连播
- 想看更深的目录，把这台服务器的「入口路径」填深一点即可（如 `有声书/历史`）
- 章节按**自然序**排好了：「第 2 集」会排在「第 10 集」前面

自动继承 App 已有的全部能力：**书架收藏、断点续听、章节列表与续听高亮、
播放模式与自动连播开关、定时关闭（含悬浮球角标）、桌面小组件**。

## 三、技术说明（为什么能播得动）

NAS 上的音频直链有三样东西会让播放器当场罢工：认证头、自签名 HTTPS 证书、IPv6 地址写法。
这一版的做法是**让播放经过本地代理**：

```
播放器 → 127.0.0.1 本地代理 → (带认证 / 放行自签证书 / IPv6) → 你的 NAS
```

好处是这些脏活都在 Java 层由 App 处理，播放器只看到一条普普通通的本地地址。
**拖进度条也照常**（代理透传 HTTP Range）。

自签名证书默认**仍然严格校验**；只有在「备份与恢复」页打开「信任自签名证书」
开关后才会放宽，而且只作用于这一条连接，不改全局安全设置。

## 四、已知限制

- **Digest 认证的服务器：能列目录，不能播放。**
  Digest 需要「401 质询 → 重算 → 重试」的交互，静态请求头无效。
  绝大多数 NAS 走 Basic，不受影响；真碰上会在保存时明确提示，
  建议在 NAS 后台把认证方式改成 Basic。
- 只识别常见音频扩展名（mp3 / m4a / m4b / flac / wav / ogg / opus / wma / ape 等），
  其余文件会被忽略而不是当成音频。
- 单目录文件数特别多时，首次列目录会慢一点（取决于 NAS 响应速度）。

## 五、合规说明

本功能是**纯工具**：App 不提供、不存储、不索引任何音频内容，
所有书目直接来自你自己的服务器，播放也直接取自你的服务器。
内容是否合规由你自己拥有的文件决定。

## 六、排障

连不上 / 播不了时，按这个顺序查：

1. 面板里的「测试连接」提示原文（它已经针对不同服务商做了分流说明）
2. 关于页 → **播放诊断日志**（会记录是否走了本地代理、认证方式）
3. 手机与 NAS 是否在同一网络 / IPv6 是否可达；开了 VPN、私人 DNS、
   广告过滤的，先关掉试试 —— 实测有链路会拦 PROPFIND
