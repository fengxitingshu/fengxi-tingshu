# 枫兮听书 v4.9.0 更新说明（2026-10-26）

> versionCode 118 · 覆盖安装数据不丢（签名一致）· 安装包体积 +4.5MB

## 本版核心：内置 FFmpeg 播放内核，WMA 直接播放

你的网盘有声书全是 **.wma** 格式，而安卓系统播放器大多没有 WMA 解码器——
这就是之前「取链成功但播放失败」的真正原因（不是软件 bug，是系统解码能力缺失）。

本版内置了 **ijkplayer（B 站开源播放器内核）**，自带 FFmpeg 软解，
WMA 全家族（v1/v2/pro/lossless/voice）都能解，**不用再转换格式**。

## 工作方式

- **自动选内核**：按文件扩展名——wma / ape / ac3 / dts / tta / tak / vqf
  走 FFmpeg 软解；mp3 / m4a / flac / aac / ogg 等仍走系统播放器（省电）
- 倍速、音量增益、通知栏、定时、自动下一集、续播、播放失败自愈
  对两种内核**同样生效**
- WMA 的 toast 提示保留（万一某本书仍失败，方便定位）

## 其他说明

- 若某本 WMA 书播放仍失败，失败 toast 后会显示「原因：…」，
  把那行文字发来即可定位
- 安装包从 19MB 增加到约 24MB（FFmpeg 解码库）
- 覆盖安装即可，书源 / Cookie / 缓存 / 播放记录全部保留
