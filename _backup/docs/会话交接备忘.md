## 一、新会话快速开始（最重要）
- **仓库**：`fengxitingshu/fengxi-tingshu`（私有），本地 `/workspace/fengxi-tingshu`
- **云端恢复**：`export FENGXI_TOKEN=<你的GitHub PAT>` → `bash /workspace/fengxi-tingshu/restore-env.sh`（自动 clone + 工具链 + 签名回填 + 试构建，约 5~8 分钟）
- **同沙箱换窗口**：`/workspace/fengxi-tingshu` 已存在时，脚本自动跳过 clone，直接 rebuild
- **无 token 兜底**：用 `/workspace/枫兮听书-恢复包.tar.gz` 解包（见第六节），再跑 restore 脚本
- **⚠️ 签名证书 `test.keystore` 必须从 `.fengxi-env/` 回填，绝不能重新生成**（防盗指纹绑定该证书，重生成用户就装不了升级包）

## 四、环境要点（构建 / 播放内核）
- **构建**：`bash build.sh`（9 闸门），JDK17 + android-35；build-tools 34（aapt2/d8）。**d8 不支持 lambda → 全用匿名内部类**；javac effectively final；依赖 jar 需手填 `DEPS`/`JAVAC_CP`。
- **双播放内核**：`src/com/tingshu/app/player/Engines.java` 定义 `Engine` 接口 + `SysEngine`(MediaPlayer) + `IjkEngine`(IjkMediaPlayer)。按扩展名 `wma/ape/ac3/dts/tta/tak/vqf` 走 FFmpeg 软解，其余走系统。
- **ijkplayer 0.8.8**：`maven.aliyun.com/repository/jcenter` 取 `java-lib/ijkplayer-java.jar` + `lib/arm64-v8a` 三个 so（ijkffmpeg/ijkplayer/ijksdl）；proguard `-keep class tv.danmaku.ijk.** { *; }`。
- **前端**：WebView，`assets/www/app.js`；扫描结果 `App.custom.pan[pid].scanBooks` 用 localStorage 持久化。
- **签名**：指纹 `62668e…4568` 不变，覆盖安装数据不丢。

## 五、推送 / 出包流程（给新会话）
- **代码**：有 token 走 `git push`；历史也用 GitHub API `PUT /repos/.../contents/<path>` 逐文件（中文路径 `quote(path, safe="/")`），4 次重试幂等。
- **Release**：Release 创建 + Assets 上传 APK（body 先最小再 PATCH）。
- **出包**：`bash build.sh` → `release/枫兮听书-vX.Y.Z.apk`；再 `mobile_share_files` 推手机。
- **网速不稳**：GitHub `curl API` 比 `git` 稳，push/fetch 常需重试。
